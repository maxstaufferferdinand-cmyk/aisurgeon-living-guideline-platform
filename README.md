# AISurgeon Living Guideline Platform

Private development repository for a scalable, source-bound living-guideline platform.

Core architecture:

- Gemini 3.5 Flash for native, PDF-adaptive source extraction
- GPT agent for search planning, evidence mapping, synthesis, and orchestration
- Codex for software development, testing, and controlled repairs
- Deterministic Python services for validation, versioning, references, and DOCX generation

Status: Early platform development.
